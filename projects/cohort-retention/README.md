# 项目 02：月度复购留存

**业务问题：** 不同首次观测购买月份的客户，在随后的完整月份中还会回来购买吗？

## 运行

在仓库根目录运行：

```bash
python main.py --demo --output reports/cohort-demo
```

查看 `index.html` 的留存矩阵；逐格人数在 `cohort_counts.csv`，比例在 `cohort_retention.csv`，图像在 `cohort_retention.png`。

## 一个可手算的例子

假设 A、B 两位客户在 1 月首次被观测到购买，A 在 2 月复购；C 在 2 月首次购买。若数据完整到 3 月 1 日之前：

| 首次观测月 | 第 0 月 | 第 1 月 |
| --- | --- | --- |
| 1 月 | 2/2 = 100% | 1/2 = 50% |
| 2 月 | 1/1 = 100% | 尚未观测 |

2 月 cohort 的“第 1 月”是 3 月，不能填成 0%。若截止时间为 2 月 15 日，2 月尚未完整，整个 2 月留存也应排除。

## 实现位置与边界

核心函数为 `olist_analytics.customers.cohort_retention`，先聚合订单，再按首次观测月和月份间隔计算去重客户数。分母始终固定为首月客户数量。源数据缺失月份无法自动辨别，须核实覆盖范围。

本指标是**购买留存**，不等于活跃留存、合同续费或真实流失概率，也不要求连续购买。详细定义见 [指标说明](../../docs/METHODOLOGY.md)。

## 验收

`python -m unittest discover -s tests -v` 包含完整月份零复购、未来月份为空、部分月份排除，以及客户身份、订单粒度的回归用例。
