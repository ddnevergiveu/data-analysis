# 系统职责与取舍

## 三个入口，共用执行层

| 入口 | 谁生成 SQL | 谁验证与执行 | 谁看到结果 |
| --- | --- | --- | --- |
| CLI 离线规则 | 六类固定模板 | `QueryEngine` | 终端与本地报告 |
| CLI Ollama | 本机服务的结构化模型响应 | 同一个 `QueryEngine` | 终端与本地报告；规划请求不附数据行 |
| MCP | 连接的 AI 客户端/用户 | 同一个 `QueryEngine` | 连接的客户端，后续处理由客户端决定 |

规划器没有直接数据库连接，也不能改变数据库路径、引擎设置或输出预算。MCP 工具同样只能读取服务启动时选择的数据集。导入与建库是用户通过 CLI 明确选择的单独操作。

## 数据契约先于模型

标准 CSV 的一行就是一笔订单。导入前验证五列、唯一订单号、稳定客户键、日期与金额，再事务写入临时 DuckDB，原子发布到新路径。已有快照不覆盖。

输入字节 SHA256 可以辨认不同文件；规范化数据 SHA256 按固定字段和订单 ID 排序，消除 CSV 行顺序或金额表示形式造成的无意义差异。元数据同时保留来源和 synthetic 标记。

日期范围只表示观测到了哪些订单，不证明数据完整；字段定义只能由数据提供者保证。金额是订单商品毛额，不自动解释为净收入或利润。

## 执行边界

SQLGlot 对完整输入解析，检查一条 SELECT、非递归 CTE、允许的查询来源、AST 节点和函数。不会仅根据字符串以 SELECT 开头就放行。SQL 规范化后交给 DuckDB 绑定和执行；未知字段、类型错误或其他不支持表达会明确失败。

连接使用只读模式；禁止外部访问和扩展自动加载、禁用临时磁盘、限制线程与内存，再锁定配置。默认计时器在查询预算耗尽后调用 DuckDB `interrupt()`，属于协作式取消，不能保证终止宿主中的任意代码。

输出多取一行判定截断，只返回上限以内的结果，明确 `truncated`。这限制输出规模，不免除底层查询计算成本。

## 结果证据与重放

证据 ID 包含规范化数据指纹、规范 SQL、返回列/行、截断标记和上限。它不包含模型自然语言解释，因为解释不是计算事实。

`verify` 从保存的答案读取执行 SQL，通过同一约束重跑，并比较快照元数据中保存的数据指纹、结果和证据 ID。它不重新扫描全表计算指纹，可发现不同的合法快照或导致查询结果改变的修改；不能认证被手工篡改的数据库。它也不是数字签名；若文件中的 SQL、结果和标识被一起重新制作，重放不能证明原始作者或最初用户意图。

Markdown 报告直接呈现数据库返回表格，不让模型改写数值。SQL 使用动态长度的 code fence，防止合法 SQL 字符串中的反引号改变报告结构。

## 当前适用范围

这是可独立运行的本地作品集项目。支持可信的标准订单数据、明确的单数据集问题和 AI 工具接口；不提供公开 Web 服务、权限系统、多租户隔离、云端部署或任意文件查询。

真实业务扩展应先引入经过确认的指标字典、覆盖范围和权限模型，再决定是否增加多表关系、时间回溯、模型准确率评估或服务部署。
