# 指标口径与数据质量

## 1. 一条数据代表什么

| 表/结果 | 粒度 | 唯一标识 |
| --- | --- | --- |
| orders | 订单 | `order_id` |
| order_items | 订单商品明细 | `order_id + order_item_id` |
| customers | 订单关联的客户记录 | `customer_id` |
| 跨订单客户 | 一位可识别客户 | `customer_unique_id` |
| orders.csv | 聚合后的订单 | `order_id` |
| rfm_segments.csv | 截止日之前的客户 | `customer_unique_id` |

Olist 的 `order_item_id` 是订单中的明细序号。例如两行价格分别为 10 和 20、序号分别为 1 和 2，商品金额应为 **30**，而不是 10×1+20×2=50。每行 `price` 只累加一次，运费单列汇总。

原发布者说明，同一客户的不同订单可以有不同的 `customer_id`；跨订单分析必须使用 `customer_unique_id`。

## 2. 销售与客户指标

- **商品销售额**：最终状态为 `delivered`、购买时间早于观察截止时间的明细价格之和。货币单位 BRL。
- **订单数**：上述样本中的去重 `order_id` 数量。
- **平均订单金额**：先汇总每单商品金额，再对订单求均值；不能用明细均值代替。
- **复购客户率**：上述样本内至少有两笔不同订单的客户数 / 全部客户数。
- **客户已观测购买跨度**：最后购买时间减首次购买时间；不声称是客户的完整生命周期或 CLV。
- **品类订单数**：在该品类出现过的去重订单数。一单可含多个品类，因此各品类订单数不能直接相加作为总订单数。

商品销售额不是净收入：未接入退款、付款对账、平台费用和利润数据。`delivered` 是快照中的最终状态，因此本项目是**事后描述分析**，不能冒充在历史时点已知的经营数据或用于无泄漏的回测。

机器学习姊妹项目使用截止时已知的下单明细预测未来下单行为，避免使用未来才知道的最终状态，故两个项目的金额口径有意不同，不能直接对比数值。

## 3. 数据质量规则

在计算前检查必需字段、空键、金额有限性和非负性、正整数明细序号、购买时间，以及订单/客户/商品外键。

按实际使用的字段识别完全重复记录并去重，数量写入 `data_quality.json`。同一主键的冲突记录会终止运行，避免多对多连接放大金额。连接使用 pandas 的 `validate` 明确校验一对多/多对一关系。

缺失品类和州显示为 `unknown`；缺失真实客户标识、未知商品关联、已交付订单缺明细等问题不猜测、不按零金额补齐。缺少任何一张表时给出具体文件名和 `--demo` 提示。

时间使用 Olist 风格的无时区本地时间；带时区或混合时区输入应先由使用者明确转换，不在程序中猜测时区。

## 4. 观察窗口与留存

`--as-of` 是**独占终点**：`2024-04-01` 表示购买时间必须早于 4 月 1 日零点。

对真实 CSV 若未给 `--as-of`，程序保守取最后一笔订单所在日期的次日，并把该推断写入质量报告。这个日期不是“数据完整”的证明。生产或业务解释前必须核实导出覆盖范围，不能把缺文件、缺月份当成没有订单。

留存以客户**首次观测购买月**分组，分母始终是该 cohort 的首月客户数。每个后续月的分子是该组当月发生购买的去重客户数。它衡量月份内再次购买，不衡量登录活跃，也不要求客户连续每月购买。

若观察截止为 4 月 15 日，4 月尚未结束，留存仅计算到 3 月；4 月订单仍可进入月度销售表，但图表和报告明确最新月可能不完整。尚未完整观测的 cohort-age 单元格为 `NaN`（CSV 空白、HTML 显示 `—`），完整月份没有复购才写 0。

截取的数据可能遗漏更早的购买，所以首次观测月不能自动解释为真实获客月。

## 5. 可解释 RFM 规则

R：距最近购买的完整天数；F：去重订单数；M：历史商品金额。按以下优先级分类：

| 分群 | 条件 |
| --- | --- |
| champions | R≤90、F≥3、M≥500 |
| loyal | R≤90、F≥2，且未命中上一条 |
| new | R≤30、F=1 |
| at_risk | R>90、F≥2 |
| hibernating | R>180，且未命中前述规则 |
| occasional | 其余客户 |

500 BRL、30/90/180 天为演示阈值，没有声称经过业务优化。同分客户得到相同分群，避免通过任意排序强行切分同值客户。真实使用前应根据复购周期、毛利、联系成本及对照实验调整规则。
